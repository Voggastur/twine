# Image generation prompts

Self-contained copy-paste blocks for AI image generation. One per passage.

## Workflow

1. Copy a single block below (everything between `---` markers) into your AI generator.
2. Attach `images/gobbo_forest.png` as style reference if the generator supports it.
3. Save output to `images/<filename>.png`.
4. Tick the checkbox below the block.
5. Insert `<img>` tag into matching passage in `index.html`:

```html
<img src='https://raw.githubusercontent.com/Voggastur/twine/refs/heads/main/images/<filename>.png'
style='width:100%; height: 100%;' />
```

## Status legend

- [ ] not yet generated
- [x] done and inserted into `index.html`
- HIGH = priority scene (start, choice hub, climax, payoff)
